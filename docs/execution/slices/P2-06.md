## 完整行为

1. `events.Appender.Append` 只接受 UoW callback 内仍有效的 txCtx；普通、过期或
   已结束 context 都 fail-closed，不自行开启事务。
2. `event_log.id` 是稳定事件身份。相同幂等键和相同事件事实返回原 ID；相同键对应
   不同事实返回 `ErrIdempotencyConflict`，不覆盖已存事件。
3. append 只写数据库，不 enqueue、不分发、不调用网络；`dispatched` 只供后续
   dispatcher 记录当前投递进度，不承诺 exactly-once。
4. 业务状态写与 append 使用同一 `pgx.Tx`，任一失败或 callback rollback 时两者
   一起回滚。
