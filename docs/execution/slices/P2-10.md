## 完整行为

1. 每个已冻结业务 operation 在 OpenAPI 同时声明稳定 capability 与逐角色
   scope；任一缺失、扩权或漂移均由 OpenAPI contract 永久负例拒绝。
2. capability 采用闭集；未知字符串、无效 principal、nil/cancelled context
   一律返回 `ErrUnauthorized`，不得通过默认角色或字符串前缀获得权限。
3. `admin` 可访问本片全部 capability；`ops` 可访问 session、customer 与
   identity 运营能力，但不能读取 config overview；`sales` 仅可访问自身
   session 与 customer 能力，不能访问 identity/config。
4. `sales` 必须绑定正 `staff_id`。其 customer scope 固定为
   `owner_staff`；`admin/ops` 的 customer scope 为 `global`。客户端 owner
   filter 不能扩大该授权；后续 contact SQL 必须在 keyset 条件前应用 scope。
5. operation 授权 middleware 固定运行在 Authenticate 之后；缺 principal
   返回 401，角色/capability 拒绝返回 403，成功则把不可变 Authorization
   放入 context。后续单对象 owner 不匹配必须映射为 404 防枚举。

## 冻结矩阵

| capability | admin | ops | sales |
|---|---|---|---|
| `auth.session.read/logout` | self | self | self |
| `customers.read/write`、`customer.events.read` | global | global | owner_staff |
| `identity.resolve/bind/ingest` | global | global | DENY |
| `config.overview.read` | global | DENY | DENY |

本矩阵只覆盖当前 G1 已冻结的 10 个 operation；后续 stages/P3 operation
必须在各自 OpenAPI 冻结片显式追加，未追加前保持 deny。

  principal、context 取消、scope/owner 与授权 context 正负路径。

  误授 ops；repo-contract 永久负例覆盖核心/证据漂移及验收目标断开/空实现。
