## 安全上传、幂等与原子性

- Media domain 只接受 PNG/JPEG/GIF。先以 `10 MiB + 1 byte` 有界读取，再以标准库
  `DecodeConfig` 真实嗅探并要求声明 MIME 与实际格式一致；宽高各 `1..10000`、总像素不超过
  `40,000,000`，随后完整 decode 拒绝截断或损坏内容。文件名要求有效 UTF-8、最多 255 rune，
  禁止 `/`、`\`、控制字符、`.`、`..` 与首尾空白。
- `media.images.write` 只授权 admin/ops global；旧路由同时要求 human browser session 与 CSRF。
  旧 UI 未发幂等 header 时仅为该请求生成随机业务键；显式键按单实例 `admin:<actor>` 与业务键
  隔离。事件 key 是 actor+业务键的摘要，不包含 tenant 语义。
- 一个 UoW 内依次完成 actor-scoped receipt reservation、`media_images` metadata、
  `media_image_blobs` 原字节、Events port 的 `media.image_created` 与 receipt completion。
  同 actor/key/规范 payload 返回 JSONB snapshot；异 payload 冲突；不同 actor 相同业务键互不碰撞；
  Event 冲突或任一写失败时 metadata/blob/receipt 一并回滚。
