## 完整行为

1. 新增 append-only `customer_events`，以 UTC `occurred_at` 按月 RANGE 分区；
   主键包含分区键，payload 必须为 JSON object，event type 与 actor 按冻结边界校验。
   父表 trigger 以 SQLSTATE `55000` 拒绝 UPDATE/DELETE，禁止只在文档中声称
   append-only 却允许库内改写。
2. 父表固化 `(customer_id, occurred_at DESC, id DESC)` 复合索引与
   `occurred_at` BRIN，新分区自动承接子索引。
3. migration 预建当月及未来三个月；唯一 SQL 维护函数只接受 0–36 个月
   窗口，以 transaction advisory lock 串行化并发 DDL。窗口外写入 fail-closed，
   不设无界 default partition。
4. worker 启动时及每 24 小时由唯一 scheduler 注册入 `heavy` 队列，严格预建
   未来三个月；无 default 队列、无 timer、无跨队列槽位借用。
5. migration 的本地验收 DSN 改为复用 P2-00 的公开安全校验，保持 CI 5432 与
   隔离本地 55432 都可显式通过，错误不回显凭据。
