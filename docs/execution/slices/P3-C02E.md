## 回退规模

P3-C02D 的 `slice_induced_correction_count=3`，本片按 AGENTS.md §4 回退为一个
简单、只读、无分页 API operation；不与客户详情 UI 或 C-6 性能验收捆绑。

## 完整行为

1. 只闭环 `GET /api/v1/tags` / `listTags`；使用冻结的 `customers.read` 能力，
   admin/ops 为 global，sales 沿用既有 owner_staff 授权但读取同一全局目录；响应固定
   `no-store` 与 non-null `items`。
2. 标签目录来自本地 `tags`/`tag_groups`，绝不返回 `wecom_tag_id`。顺序固定为：
   已分组标签按 `tag_groups.sort_order, tag_groups.id, tags.sort_order, tags.id` 升序，
   未分组标签最后按 `tags.sort_order, tags.id` 升序。
3. `group_id` 与 `group_name` 必须同时存在或同时为空；标签 ID、组 ID、名称与
   sort_order 任一存储污染均 fail-closed 为稳定 503，不返回部分目录或底层错误。
   重复标签 ID、非稳定顺序与同一组出现不一致名称也必须拒绝。
4. store 必须从 transaction-bound context 取 tx；service 在 UoW 内读取一次目录；
   handler 只使用 generated wrapper，运行时接入真实 store/service/handler。

## 非范围

  或鉴权模型。
- 不实现标签写入、企微标签同步、客户详情 UI、生产数据读取或外部调用。
