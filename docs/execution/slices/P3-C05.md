## 完整行为

1. 从客户列表进入 `/customers/{OneID}`，精确解析正整数 OneID；非法、缺失或带额外
   path segment 的地址 fail-closed 为 404，不把 query/hash 当作 ID。
2. 详情页只通过现有 Orval generated client 读取 `getCustomer`、`listTags` 与
   `listCustomerEvents`；固定 `credentials: same-origin`，严格解析服务端响应，展示
   loading、empty、401、403、404、503 与 retry 分支。
3. 资料、阶段与本地标签操作只调用已冻结的 `updateCustomer`、`setCustomerStage`、
   `addCustomerTag`、`removeCustomerTag`。写请求必须携带服务端绑定的 CSRF token；
   缺 token、重复提交、非法 OneID/tag/stage/profile 均 fail-closed。
4. 不做 optimistic update。写成功后重新读取服务端详情、标签目录与时间线；若写成功
   但回读失败，明确提示结果待确认，不把本地预测展示为数据库事实。
5. 页面不得展示 external identity 或 `wecom_tag_id`；渠道中立边界继续由现有 API
   response parser 与服务端合同双重守住。服务端仍是 RBAC 与 owner scope 的唯一真相。

## 规模例外

该 UI flow 同时包含资料编辑、阶段、标签、时间线、严格 generated transport/parser 与
完整错误/可访问性分支；拆开会产生不能独立使用的半页面。已存在 Terra 载荷的非测试
最终生产手写规模为 5 文件 / 1499 个物理变更行（1492 新增、7 删除），
超过 P3 默认 1000，但低于 15 / 1500 硬顶。该数字已包含列表入口与精确动态
路由接线；测试、中央验证夹具、收据与治理文档不计入手写额度。
