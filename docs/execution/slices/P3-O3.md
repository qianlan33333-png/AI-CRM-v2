## 冻结行为与边界

- 同 key 同规范化命令返回原 batch/event 并跳过已提交 chunk；相同 key 异命令冲突。
- batch accepted 事实先独立提交；每个 chunk receipt 与其全部 task/event/job 在同一事务提交或回滚。响应丢失后重试从首个未展开 chunk 继续。
- 20 万收件人按档位分别使用 200/40/20 个有界 chunk UoW，不持有一个跨 20 万条的大事务。
- task ID、batch ID、chunk ID 均由 PostgreSQL `GENERATED ALWAYS AS IDENTITY` 生成；应用不显式写 ID。
- River 只插入稳定 `outbound_enqueue_batch_task` 参数，不注册或运行 worker，不调用企微。
- 不含 O-4 sender、O-5 状态、O-6 重试取消、API、UI、OpenAPI、生产数据库、live migration、真实企微或真实外发。
