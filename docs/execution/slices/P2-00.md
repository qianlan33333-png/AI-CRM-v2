## 冻结合同

1. 夹具表只能显式限定为 `acceptance_fixtures.<table>`；不接受路径、包名或
   测试文件名白名单。
2. helper 只连接 loopback 的 `postgres`/`aicrm_test` 测试数据库，持有 advisory
   lock，启动时重建专用 schema，结束时删除 schema 并释放连接。
3. ownership lint 同时扫描 `internal/**` 与 `acceptance/**` 中的 SQL 字符串；
   `CREATE TABLE public.<unknown>` 永久负例必须失败，专用 schema 正例必须通过。
4. P2-01 原片保留两次 correction 并标记 `SUPERSEDED_BY_RESCOPE`；归因改为
   `scope_induced`。P2-01R 是新片，不得通过修改原片计数继续修补。
5. 验收 DSN 固定用户/密码/数据库与 `sslmode=disable`，只允许字面量
   `127.0.0.1`/`::1` 和 1–65535 动态端口；P0-S03、P2 helper 与 query-plan
   共用同一安全边界，CI 用 5432，本地隔离实例用 55432。
6. `scripts/**` 中的 shell 循环和局部声明禁止使用 `path/PATH/IFS/HOME/PWD/`
   `SHELL/LANG/UID/STATUS`；repo-contract 扫描 Git index 并保留永久负例。
