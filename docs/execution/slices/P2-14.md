## Schema 与 port 冻结

1. 本片复用 `00001_bootstrap.sql` 已有 `stages` 表：`id BIGINT IDENTITY`、
   `name TEXT NOT NULL`、`sort_order INTEGER NOT NULL`、
   `config JSONB NOT NULL DEFAULT '{}'`。不改 migration，不增表、时间戳、软删除或
   无证据的唯一约束。
2. `stages` 由 contact 独占写；查询只允许按 `sort_order ASC, id ASC`
   确定性排序，阶段数为小配置集，不做 `COUNT(*)`、OFFSET 或分页。
3. 公共 `contact/port` 冻结 `Stage`、`CreateStageCommand`、
   `RenameStageCommand`、`StageService` 与稳定错误。当前 G2 浏览器行为
   只要求列表、新增和改名；本片不自行发明删除、重排或 config 编辑语义。
4. store 仅从 transaction-bound context 取 pgx transaction；无 UoW 必须
   fail-closed。`INSERT` 和 `UPDATE ... RETURNING` 必须返回数据库事实，
   改名未命中统一转为 `ErrStageNotFound`。
