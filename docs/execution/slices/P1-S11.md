## Goal

冻结供 G1 抽查的 10 个 contact/identity/auth/admin 候选接口，以及 P2/P3 所需最小跨域 Go port；不提交业务实现或假装接口已获产品签字。

## Candidate OpenAPI

- contact：列表、OneID 详情、资料更新、append-only 时间线，共 4 个 operation。
- identity：Resolve、Bind、Ingest，共 3 个 operation。
- auth：admin session 与 logout，共 2 个 operation。
- admin：仅非 secret 的 config readiness overview，共 1 个 operation。
- 每个 operation 均用 `x-legacy-mapping-ids` 关联 frozen mapping，共 14 个链接；状态全部为 `PENDING_HUMAN_SIGNOFF`。
- `Customer` 禁止 external_userid/unionid/openid/phone/mobile；`IdentityRef` 强制 `type/scope/value/assurance/source`。
- 列表只接受 keyset cursor；错误继续统一 `ErrorResponse`；默认 admin session 鉴权，healthz 例外。

## Public ports

- `contact/port.MergePort`：CreateForIdentity、MergeCustomers、AppendExternalEvent，只持有 OneID，不持有渠道 ID。
- `identity/port.Service`：Resolve/Bind/Ingest，显式 status，不把冲突折叠为 bool。
- `auth/port.Service`：opaque SessionRef 的认证、能力授权与失效；禁止记录或暴露 session。
- `platform/port.UnitOfWork`：只冻结 transaction-bound callback 形状，不提供实现。

3. oapi-codegen 与 Orval 连续生成两次无 diff；生成 server/client 可编译。
4. 作者测试验证 generated DTO 与 port surface；arch-import lint、repo-contract/runner、全 CI 通过。
