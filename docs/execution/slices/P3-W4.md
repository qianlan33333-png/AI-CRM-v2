## 可观察行为

- 对单一 WeCom staff userid 读取一页外部联系人 ID，验证 ID 与 cursor 的闭合形状。
- 仅在事务中以当前 cursor CAS 持久化下一 cursor；同一旧 cursor 的并发落败方重新加载状态，而不会返回已由胜者提交的页面。
- 服务重启后从已持久化 next cursor 续跑。末页写入完成态，后续调用稳定返回完成而不重新读取第一页，因此可观察输出没有重复页。
- `wecom_sync_state` 只存同步键、opaque cursor 与完成状态；不建档、不归因、不写 Contact/Identity，也不调用 callback、worker、UI 或任一企微写接口。
