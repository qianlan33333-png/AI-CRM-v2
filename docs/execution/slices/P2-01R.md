## 完整行为

1. `platformstore.UnitOfWork.Within` 在单一 PostgreSQL transaction 内执行 callback；
   成功才 commit，callback error 或 panic 整体 rollback。
2. transaction context 只能在 callback 存续期间由 `TxFromContext` 使用；
   返回后为 `ErrTransactionRequired`，嵌套 `Within` 为 `ErrNestedTransaction`。
3. PostgreSQL serialization failure `40001` 与 deadlock `40P01` 最多重跑完整
   callback 三次，不得从中间步骤续跑。
4. 真实 PG 验收只在 `acceptance_fixtures` schema 建探针表，复用 P2-00
   helper；不创建业务表或 contact 包文件。
5. 同步 P3 波次、分片规模、M1–M6 作废、backlog 边界，以及 River
   六队列、`inbox_events`、`outcome_unknown`、`event_deliveries` 推迟 P4。
