## 领域、权限与传输合同

- Order-owned projection 只保存订单列表所需事实与 Customer/Product 快照；可选名称增强只经最小只读 port，
  不跨域读表、不建跨域 FK。依赖不可用 fail-closed，记录不存在回退本域快照。
- 人类 A01 session 使用精确 `order.read`；admin/ops 为 global，GET 不要求 CSRF。查询只接受
  `provider/order_no/mobile/product_code/created_from/created_to/status/limit/offset`，未知、重复、越界与倒置时间均拒绝。
- 成功响应顶层精确四键 `items/total/limit/has_more`；金额固定两位，商户订单号、平台交易号和身份字段保持冻结别名。
  错误 DTO 只有 `message/error_code`，映射 400/401/403/404/409/503。

## 数据、性能与回放

- `00035_order_list_projection.sql` 在实时 main 水位 34 上新增两个 Order-owned 表；single-instance、无 tenant/RLS、
  无跨域 FK、无付款/退款/回调/外发语义。批量计数采用 statement transition tables，避免逐行热点更新。
- loopback PG16.14 已真实连续观察 `34→35→34→35`：22 个约束、10 个索引、invalid=0；Event/Auth/session
  历史行数与哈希全程不变。
- S 档 200,000 行装载后 counter 与事实数均为 200,000，清理后均为 0；list、merchant substring、product count、
  exact-total 计划分别使用 Index Scan、Bitmap Index Scan、Index Only Scan 与 counter PK，无 order projection 非法 Seq Scan。
- normal/boundary/error、A01/RBAC、HTTP/root/OpenAPI/generated、Customer/Product port fail-closed、race/vet/static
  及直接消费者 current-waterline 回放均属于本片 focused gate；不重跑无关系统。
