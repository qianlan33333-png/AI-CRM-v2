## 安全与黑盒证据

- redirect 永久负例拒绝反斜杠、`//`、绝对 URL、单层/多层编码绕过、控制字符、CRLF、fragment
  与 dot segment；包含历史事故输入 `/\evil.example/path`。
- nonce 原文和 session/CSRF 原文不落库；nonce 单次原子消费在 provider 调用之前完成，replay 不再
  调用 provider。OAuth state cookie 为 Secure/HttpOnly/SameSite=Lax 且仅 callback path。
- 非生产 provider adapter 黑盒冻结 token 与 enterprise userid exchange；OpenID-only 身份拒绝。
  真实企微调用不作为代码 CLOSED 条件，也未执行。
- `gate/55431` 的 PG16.14/server `160014` 全链证明 human identity 实际签发 session、
  `/api/v1/auth/session` 经过 RBAC/capability 返回 admin、错误 CSRF 返回 403 且 session 仍有效、
  正确 CSRF logout 后 DB `revoked_at` 生效且旧 session 返回 401。
- S 档 20 万 `admin_oauth_states` 的真实 claim `DELETE ... RETURNING` 使用
  `admin_oauth_states_pkey` Index Scan，无非法 Seq Scan。

## 复用基座与明确未建设能力

- 保留供 A02/A03、F01A 与后续旧 UI 写接口复用的最小基座：composition-root 人类登录接线、
  已合 canonical/legacy session cookie 兼容、session-bound CSRF middleware、一次性 OAuth nonce、

- 这些后续片无需重复实现 provider code→actor、cookie 签发、RBAC/capability context、CSRF 绑定和

  设备指纹、异常登录/告警平台、运维 UI/dashboard、恢复器、多 provider SSO、新产品语义。
