- ADR-012 要求 reservation、业务写入、event_log 与 completed result 处于同一 transaction-bound UoW；禁止提交 `in_progress` 或跨 UoW completion。

## 可观察行为

- 00013 只替换 deferred complete-before-commit trigger 所调用的函数：延迟检查按 receipt 主键读取事务内最终持久化状态，而非使用首次 INSERT 触发事件的旧行镜像。
- 合法的 reservation → Contact-owned business write → completed 在一个 PG16.14 UoW 中提交成功；receipt 仍为 completed 且业务事实一同提交。
- `in_progress` 不能提交以等待另一事务完成；第二连接看不到未提交 reservation，rollback 后该 reservation 不存在。
- 原有 completed-result 形状、operation/result 对应关系、result schema version 与 completed 后不可变约束保持 fail-closed。
