## 可观察业务行为

- admin/ops 以全局 capability 分页读取 pending review；只返回 Kind、canonical scope、
  两个排序 candidate customer roots 与 versioned secret-backed HMAC，禁止 raw/normalized
  identity 泄露。
- approve 必须显式选择候选中的 primary，并在同一 UoW 内锁定 pending/version/evidence/
  两个仍 active 的 roots，执行 contact-owned MergeCustomers、Identity 重绑、manual
  customer_merges 审计、`customer.merged` event、review 完成与 receipt 完成。任一漂移
  返回 409 且零副作用；任一步失败整体回滚。
- reject 只原子完成 review 与 receipt，不改 binding/customer、不写 merge audit/event。
  approve/reject 同 key 同 canonical command 重放原事实，异 payload fail-closed。
- API 启动新增强类型 `AICRM_IDENTITY_HMAC_KEY`（32-byte canonical base64url）并保持
  `String/GoString` redacted；该 key 只用于既有 Identity HMAC/receipt 语义。
