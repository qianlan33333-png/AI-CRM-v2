## 可观察行为

- 三个 callback 值（CorpID、Token、43 字符 EncodingAESKey）必须同时存在且格式合法；完整缺失时入口稳定为 `503 callback unavailable`，部分或畸形配置使 API 进程 fail-closed 启动失败，错误与格式化输出均不回显 token 或 AES key。
- GET 对 `msg_signature=sha1(sort(token,timestamp,nonce,echostr))` 使用常量时间比较，验签后以 AES-256-CBC、企微 32-byte PKCS#7 padding 解密 `echostr`，并原样返回明文。
- POST 只校验 query 签名、外层 XML `ToUserName`、密文、解密帧 receiveid 与内层 XML `ToUserName` 都等于配置 CorpID。成功时只返回经同协议加密、可验签/解密为 `success` 的 ACK。
- 两条入口共享同一行为，且在 admin authentication/CSRF 之外挂载；其访问日志仍只记录路由模板。
