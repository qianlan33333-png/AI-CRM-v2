# M0-7：gitleaks OpenAPI 版本误判修复

## Objective

在不降低真实密钥检测强度的前提下，修复 gitleaks 8.30.1 将 Orval
生成注释中的公开 OpenAPI 语义版本误判为 `generic-api-key` 的问题。

## Scope

- 精确允许 `web/src/api/generated/*.ts` 中完整且独占的 OpenAPI 语义版本注释。
- 豁免仅对 `generic-api-key` 规则生效；路径、整行正则和规则 ID 必须同时命中。
- 工作流显式使用被锁定的 `.gitleaks.toml`，并运行独立永久回归。
- 不修改 PR #94 的 OpenAPI 决策、生成物或验收断言。

## Acceptance

1. 当前 G1 语义版本注释在指定生成路径中通过。
2. 同一生成目录中的真实样例 API key 仍由 `generic-api-key` 拒绝。
3. repo-contract 锁定配置、测试、workflow 调用与模式；删除或断开任一项必须失败。

## Boundaries

- 归因：PR #94 的 `infra_induced_correction_count=1`；本片是独立基础设施修复。
- 本片 `slice_induced_correction_count=0`、`infra_induced_correction_count=0`。
- 真实企微、生产数据库、部署、迁移：`NOT EXECUTED / PENDING_EXTERNAL_GATE`。
