# P3-O2：单人外发任务的原子入队

## 输入与目标

- Base SHA：`2566eca1329f3234a6e6b9db4926ba745984dadd`，其三门 exact-main CI 已成功。
- 复用 O1A-R3 已合入的 `outbound_tasks` 与 `outbound.accepted` 同 UoW 持久化边界。
- 目标：合法单人命令在同一 PostgreSQL 事务中创建任务、accepted event、receipt 与固定
  River `outbound` job；匹配命令重放原事实，不同命令 fail-closed。

## 冻结行为与边界

- `00016_outbound_enqueue_one_receipts.sql` 仅持久化幂等 receipt 与 task/event/job 三个事实；
  task ID 始终由数据库 identity 生成。
- River 仅插入 `outbound_enqueue_one` 稳定参数到既有 `outbound` 队列；本片不注册 worker，
  不消费 job，不调用企微或任何真实外部发送。
- 同 key 同规范化命令从两条独立 PostgreSQL 连接返回同一 task/event/job；同 key 异命令冲突。
  job 插入失败时 receipt、task、event 与 job 均回滚。
- 不含 O-3 批量、O-4 sender、状态、重试、API、UI、OpenAPI、public port、root dependencies、
  生产数据库、live migration、真实企微或真实外发。
