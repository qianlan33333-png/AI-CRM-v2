## 状态、商品门与原子性

- 生命周期仅允许 `draft → published → stopped`；publish/stop 同状态 no-op，派生可用状态为
  `draft/stopped/scheduled/active/sold_out/ended`。create 旧 route 没有 `Idempotency-Key`，服务端仅生成技术收据键，响应明确
  `create_replay_safe=false`，不宣称 create replay-safe。
- publish 通过 J-owned 最小 `ProductReader` 复用 I01A Product 只读 port；target ref 缺失、重复、额外类型、非 canonical ID、
  Product 不存在、非 CNY、空价或折扣不严格小于每个商品价格均 fail-closed。Coupon 不跨域直读 Product 表。
- create/update/publish/stop 的业务事实、技术 receipt 与 Coupon Event 共用 platform UoW；四故障点全部回滚。
  已领取后规则和 targets 冻结，`total_issue_limit` 只允许增加；并发 publish/stop 收敛为各一个 Event。
