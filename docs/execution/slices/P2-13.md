## 完整行为

1. 增加精确 `/login` 页面。未认证访问任意受保护 route 时显示登录页；因本片
   不获权实现真实企微 OAuth exchange，页面必须诚实显示企微登录入口待外部门，
   不生成二维码、不发起 provider 请求、不伪造可用登录链接。session 网络/服务
   异常与 401 必须区分，异常态可重试但不得假定已登录。
2. 只消费 `GET /api/v1/auth/session`。响应必须满足正整数 `admin_user_id`、
   `admin|ops|sales` 闭集；可选 `staff_id` 只能为正整数，且 sales 缺少正
   `staff_id` 必须 fail-closed。未知状态、畸形 JSON、5xx、网络错误均不形成
   principal 或权限。
3. 浏览器进程内 permission/session cache TTL 精确为 60,000ms：同一 in-flight
   请求合并；TTL 内复用；到期重新取；只缓存已验证 200。401、异常和畸形响应
   不缓存。缓存不写 localStorage/sessionStorage/IndexedDB/cookie，不保存或读取
   `aicrm_session` bearer，logout 成功或 401 时主动清空。
4. 侧栏只由 P2-10 已冻结 capability 推导，且不是服务端授权边界：所有有效角色
   可见概览与客户；只有 admin 可见设置。stages/segments/outbound 的 operation
   capability 尚未冻结，本片必须隐藏；对应域冻结片再显式开放。直接访问占位
   route 仍不能产生未授权 API 请求。
5. 退出只从当前页面 cookie 读取唯一、43 字符 RawURL 形状的 `aicrm_csrf`，以
   `X-CSRF-Token` 调用生成 client；缺失、重复或畸形 token 不发请求。204 清空
   cache 并进入登录页；401 同样清空；403/网络错误保留当前 principal 并给出
   可重试错误。token 不进入日志、DOM、错误文本或持久化存储。
6. 已认证 shell 显示角色标签与退出按钮，保留 P2-12 的 History API、skip link、
   唯一 `h1`、键盘 focus、窄屏和 reduced-motion 行为。authenticated `/login`
   显示“已登录”账号卡与返回工作台，不做隐式外部跳转。

## 明确不做

- 不实现或调用真实企微 QR/OAuth，不新增 login start/callback API，不读取/保存
  Corp Secret、callback token、AES key；G2 真实浏览器登录继续为
  `PENDING_EXTERNAL_GATE`。
- 不把客户端侧栏当授权边界，不缓存服务端 Authenticate 结果，不允许撤销 session
  因 60 秒缓存继续访问 API。
- 不连接生产数据库、不部署、不调用真实企微、不执行 live migration。

手写生产范围为 `5 files / 814 changed lines`，文件数低于 P2 上限，
行数超过 800 软上限 14 行但低于 `15 / 1500` 硬顶。原因是 session 验证、
CSRF/logout、缓存失效、权限侧栏和登录态必须在同片形成 fail-closed
完整行为；再拆分会产生可见导航先于权限校验或登出失效不完整的
中间状态。测试、文档、收据与 ledger 按既定口径排除。
