原脚本把唯一的 `test_root` 删除权直接挂在 `EXIT` trap，同时运行后台 watchdog。
macOS Bash 5.3 的异步子 shell 可见父 shell 的 `EXIT` handler；Bash 3.2/5.3 的
`BASH_SUBSHELL` 都可区分父、子执行上下文（5.3 另有不同的 `BASHPID`）。因此将
删除权限定给创建目录的父 shell，并消除 watchdog，避免任意异步 shell 触碰根目录。

## 修复机制

- `cleanup_test_root` 只在原始 owner 的 `BASHPID`（Bash 3.2 fallback 为 `$$`）和
  `BASH_SUBSHELL` 同时匹配时删除精确的 `mktemp` 目录。
- 删除后台 watchdog；父 shell 在信号发出后最多轮询 `20 × 0.1s`，超时即
  `SIGKILL`、`wait` 回收并以失败退出。
- 保留既有 API=`SIGINT`、worker/all=`SIGTERM` 合同、取消前 liveness 检查，以及
  每个角色必须 exit 0 的断言；不会把产品提前退出或非零退出伪装成通过。
