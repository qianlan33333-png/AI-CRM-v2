## 会话、幂等与原子性

- 三条路由只接受 A01 human session；read 使用 `questionnaires.read`，create 使用
  `questionnaires.write`，均仅 admin/ops global。create 必须通过 session-bound CSRF：旧 UI 无 header
  时仅允许 same-origin 请求携带 canonical/legacy CSRF cookie；显式合法 header 继续兼容。
- 缺少 `Idempotency-Key` 时只为当前请求生成随机键；显式键按 actor scope 隔离。相同 actor/key 与
  canonical payload 精确重放，异 payload 冲突，不同 actor 不共享结果。
- 一个 UoW 内完成 receipt reservation、questionnaire/questions/options、exact-total counter、
  `survey.created` Event 与 receipt completion；Event 冲突时全部回滚。
