## Route、鉴权与幂等合同

- `GET /api/admin/push-center/jobs`：支持 `business_id`→Outbound `batch_id`、冻结 task
  status、owner、`limit/offset`；无法安全映射的旧筛选稳定返回 400。
- `GET /api/admin/push-center/jobs/{job_id}`：读取单条 task、最新 Outbound-owned job link
  和真实 task 投影。
- `GET /api/admin/push-center/jobs/{job_id}/reconciliation`：同一快照读取 O6A attempt
  history 与 O6B1/O6B2 completed control receipts；只有 `sent + provider_message_id` 才输出
  `provider_receipt` 和 `delivery_proven=true`。
- `POST .../{job_id}/cancel` 与 `POST .../{job_id}/retry`：分别直接调用 O6B1
  `CancelService` 与 O6B2 `ManualRetryService`；要求 session-bound CSRF 和唯一
  `Idempotency-Key`，返回已提交的 control receipt，不调用 provider。
- `outbound.read` 对 admin/ops 为 global，对 sales 为 owner_staff；SQLC 查询把 owner
  作为数据库谓词，跨 owner 统一表现为 404。`outbound.control` 只允许 admin/ops global，
  sales 及未知 principal fail-closed。
