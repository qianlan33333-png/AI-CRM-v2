## 可观察行为

- S02 Program 先读取 all-customers universe，再按稳定 AST 遍历调用 12 个固定 leaf sqlc
  query；AND/OR 在 Go 中执行确定性交/并集，内部 complement 使用同一 universe。DSL v1
  仍拒绝 `not`，本片不扩展 parser 或公共 DSL。
- 所有 OneID 结果在集合运算前校验为正 int64、排序、去重；最终结果必须属于本次 universe。
  `is_deleted=true` 与 `false` 双向语义完整，不暗加 active-only 条件。
- 用户值只能以 `int64`、`[]int64`、UTC `timestamptz` 或 `boolean` 进入强类型 sqlc bind；
  SQL 只存在于 `internal/segment/store/queries/audience.sql`。禁止 raw identifier、SQL 文本、
  ORM、动态 builder、直接 pgx Query/Exec/Prepare 或 escape hatch。
