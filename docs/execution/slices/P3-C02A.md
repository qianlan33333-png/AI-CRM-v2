## 完整行为

1. PATCH 客户资料、设置/清空阶段、幂等添加/移除一个标签均只写 contact-owned 表。
2. 每个真实状态变化在同一个 PostgreSQL 事务中同时写 append-only
   `customer_events` 与 `event_log`；任一写失败时全部回滚。
3. 相同阶段、已存在标签与已移除标签保持幂等，不重复生成时间线或 domain event。
4. 非法 customer/tag/stage、已删除客户、非法 actor 或非法 patch 均 fail-closed；
   不引入 external identity 字段，不跨域直写。
5. 本片冻结应用 service/store 合同并以真实 PostgreSQL 验证 commit、rollback、
   幂等、事件一致性与 FK 冲突；HTTP 映射另由 P3-C02C 完成。
6. `updateCustomer` 现有路由在 handler 落地前先修正为强制 CSRF；同时将该
   OpenAPI operation 必需的 `customer.updated` 作为加法事件合同固化，避免
   资料写入违反“状态变化必须同事务写 event_log”的铁律。
7. OpenAPI gender 与既有 PostgreSQL `SMALLINT` 统一冻结为 `-32768..32767`；
   P3-C02C 必须做有界转换，并用 presence-aware JSON 解码区分 omitted 与 null。
