## 完整行为

1. `GET /api/v1/customers/{customer_id}` 返回渠道中立 Customer 与该客户已应用的
   本地标签；不返回企微标签 ID 或任何 external identity。
2. admin/ops 使用 global scope；sales 必须把自身 `owner_staff_id` 下推为 SQL
   谓词。越权与不存在都返回稳定 404，禁止泄露客户存在性。
3. 客户与标签必须由同一条 SQL 在同一 statement snapshot 中读取；store 仍须使用
   transaction-bound context。禁止在默认 READ COMMITTED UoW 内用两条 SELECT 冒充
   同一快照。应用层拒绝非法 customer、重复标签、owner 逃逸与不稳定排序。
4. 标签固定按 `(group_sort_order, sort_order, id)` 升序，group 与 group_name
   必须同时存在或同时为空；返回数组不得为 null。
5. HTTP 层只使用冻结 generated wrapper，响应继续复用严格 Customer 转换和统一
   no-store/error envelope。`extra` 只允许渠道中立业务扩展；任意层级的 unionid、
   各渠道 openid/userid、external_userid、phone/mobile、wecom_tag_id、alipay_user_id
   `ext:<namespace>` 或 identity kind/value 容器（含 camelCase、空格和分隔符变体）
   均读写双向 fail-closed。
   非正数 path ID 按冻结响应集合隐藏为 404，不产生未声明的 400。
