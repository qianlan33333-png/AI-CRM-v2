## Operational meaning today

`/health` gives a load balancer or operator a configuration-derived runtime-mode snapshot: whether the process is on PostgreSQL or fixture data, whether it is dangerously running production against fixtures, and whether the named configuration values are present. It is not readiness: it does not prove a live DB connection, River/worker health, provider reachability, or deploy success. It is mounted on the v2 router but this branch is not merged or deployed, so production load balancers do not see it yet.
