## 完整行为

1. 建立不依赖新根依赖的 History API 前端路由：精确支持 `/`、
   `/customers`、`/stages`、`/segments`、`/outbound`、`/settings`；未匹配
   pathname 显示统一 404 页。query/hash 不参与 route key，路由不使用
   prefix/default 推断。
2. 同源站内导航拦截普通左键点击，调用 `history.pushState`并派发
   route change；保留 modifier key、非左键、`target` 与站外链接的浏览器
   原生语义。`popstate` 能驱动 back/forward 重新渲染，卸载时清理监听。
3. shell 提供 skip link、product header、可注入的 navigation 区、有唯一
   `h1` 的 main content 与环境状态区；完整键盘 focus、窄屏和
   `prefers-reduced-motion` 退化。视觉定向为“编辑感运营指挥台”：暖色
   纸感底、深墨色结构、朱红小面积强调，不使用外部字体/图片或
   紫色渐变模板。
4. 本片的六个 route 页面只表达模块边界与实现状态，不伪造业务
   数据、已实现 API 或浏览器验收。`/stages` 为 P2-17 预留稳定
   route，其余业务页由后续切片替换占位内容。
