## 验收

- 矩阵 schema 与 ADR-010 一致，`feature_id` 唯一且稳定。
- 61 个 UI/page flow 与 5 个 API-only/retired flow 共 66 行，逐行引用旧源码证据。
- 首次状态统一为 `UNREVIEWED/NOT_STARTED/NOT_RUN/PENDING_HUMAN_SIGNOFF`；不得从
  `retired`、fixture、queued、HTTP 200 或静态标签推导产品处置和真实验证。
- owner scope、Secret 一次性显示/no-store、OAuth/企微外调、queued/blocked、404/410
  等高风险边界在行内保留。
- 三个手写文件、手写 diff 不超过 400 行；staged repo-contract、永久负例、gitleaks、
  PR CI 与合并后 main CI 必须通过。

- 本 Slice 不是 G1 产品签字，也不证明旧页面在线上可达。
