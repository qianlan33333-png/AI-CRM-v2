## 冻结范围

本候选只覆盖同一“问卷提交后运营配置”用户目标的五条旧路由：

| Mapping | 方法与路径 | 非中央候选边界 |
| --- | --- | --- |
| LEGACY-API-0067 | `GET /admin/questionnaires/{questionnaire_id}/operations` | 返回既有 operations 页面载体；缺失、不可用或评测不可用时为 placeholder，不新增 HTML/JS/CSS。 |
| LEGACY-API-0436 | `GET /api/admin/questionnaires/{questionnaire_id}/operations` | 返回问卷拥有的运营配置只读投影。 |
| LEGACY-API-0437 | `PUT /api/admin/questionnaires/{questionnaire_id}/operations/completion` | 保存 completion 的 canonical navigation-target 引用及可选 Channel 绑定；不执行跳转或提交后动作。 |
| LEGACY-API-0438 | `PUT /api/admin/questionnaires/{questionnaire_id}/operations/external-push` | 保存 opaque 外推配置引用；不读取 URL、secret、历史重试或历史外效。 |
| LEGACY-API-0439 | `POST /api/admin/questionnaires/{questionnaire_id}/operations/external-push/test` | 仅创建 queued job receipt；绝不发起 provider 调用。 |

依据为 `docs/api-mapping.jsonl` 中五个 Mapping 的 human-session/global capability/CSRF 元数据，以及 feature matrix 对独立运营页、完成后动作、外推配置和“排队不是投递 receipt”的冻结说明。没有读取或迁移旧 Python、旧 URL、secret、retry/lock 或历史外效。

## 产品与安全合同

- 0067、0436：future M HTTP adapter 只接受 human session，并向 service 传入 global `admin_read`、`CSRFRequired=false` 的授权要求。
- 0437、0438、0439：future M HTTP adapter 只接受 human session，并在调用 service 前验证 CSRF；service 要求 global `manage_questionnaire`、`CSRFRequired=true`。
- completion target 经 `CompletionTargetReader` 验证；服务不复制 redirect 逻辑。若该 target 需要渠道绑定，只经 `ChannelReader` 读取可选 Channel，不导入或直查 contact 表。
- 0439 的唯一成功形状为 `status="queued"`、`attempt_count=0`、`side_effect_executed=false`、`provider_result_received=false`、`unknown_after_dispatch=false`。任一其他形状（包括 `unknown_after_dispatch`）均 fail-closed，且没有自动重试路径。
- 配置保存只产生问卷运营配置事实和幂等 receipt；不等于 redirect、提交后动作、排队以外的外推、provider 接收或真实外部效果。
- 服务及测试不记录 PII、URL、secret、外推正文或 provider 响应。

## 候选实现

新增 `internal/survey/app/operations.go` 和 focused tests。`OperationsStore`、completion-target reader、Channel reader 与 queue 都是 survey app 内部 seam；当前没有具体 repository、迁移、worker 或 provider adapter。每个配置保存和 queued receipt 均在同一 UoW 中附加现有 `survey.updated` 业务事实，并使用 actor-scoped payload-digest receipt 保证幂等回放。

可能的未来 survey-owned schema 仅为设计交接，未创建 migration、未分配编号、未更新 waterline：

- `survey_questionnaire_operations`：以 `questionnaire_id` 为 owner key，保存 opaque navigation-target / external-push configuration reference 与可选 Channel binding。
- `survey_questionnaire_operations_receipts`：保存 operation、actor scope、key/payload digest、state 和安全 result snapshot。
- 队列记录由未来的外效基础设施承载；job 只能持有问卷 ID、actor、receipt ID 和时间，不能复制 URL、token 或请求体。
