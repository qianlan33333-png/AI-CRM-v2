## 目标

在 Identity 实现前闭合 contact-owned 的不可逆前置能力：渠道中立建档、两客户原子合并、合并谱系时间线，以及外部事件 exactly-once 收件。Identity 仍是上层 UoW 编排者；本片不得写 `identities`、`customer_merges` 或 `event_log`。

## 冻结语义

- `CreateForIdentity`、`MergeCustomers`、`AppendExternalEvent` 只接受 transaction-bound context，禁止内部另开事务。
- 合并按 customer ID 升序锁定两个 customer；primary 保留，merged 软删除，标签做集合并，写 contact-owned lineage。相同方向重放在后续 lineage 合并后仍幂等；反向、自合并、缺失、无同向 lineage 证明的 deleted primary 或冲突链 fail-closed。
- 主客户时间线递归包含所有 lineage 后代的历史事件；原事件 payload/actor/occurred_at 不重写，merged ID 直接读取仍为 not-found。
- 外部事件以独立 registry + 事务 advisory lock 固化 idempotency key。同 key、同事实及同 effective root 返回原 EventID；同 key 异事实返回 `ErrExternalEventConflict`，不得盲插或覆盖。
- `customer_events` 继续按 `(occurred_at,id)` 分区且 append-only；不得向分区表强塞不可能成立的全局 idempotency 唯一约束。

## 数据与回滚

- `customer_merge_lineage`、`customer_event_idempotency` 均归 contact owner。
- 任一 SQL 或后续 Identity/events 编排失败，由 caller UoW 回滚 customer、tag、lineage、timeline 与 registry 全部变化。
- rollback 为本片提交反向迁移；不会连接生产数据库或执行 live migration。
